# Rubric: report / research / audit / plan delivered to the owner
Includes `_common.md`.

- R1 MUST — Answers the question actually asked, in the first 2-3 sentences (verdict or recommendation first, detail after).
- R2 MUST — Every claim that matters has a source: a link, a command output, a file or a measurement. The reviewer spot-checks at least 3 and they hold.
- R3 MUST — Numbers are consistent (totals add up, units stated, dates and time zones right) and trace to real data — no invented tables.
- R4 MUST — Plain English for a smart non-specialist: acronyms explained, no file paths/PIDs/hashes in the main text (an appendix is fine).
- R5 MUST — Recommendations are concrete: next action, owner (agent vs owner), cost or risk. Items needing the owner's OK are clearly separated.
- R6 SHOULD — States what was NOT checked and the confidence level; separates fact from inference.
- R7 SHOULD — Skimmable on a phone (headings, short paragraphs), no padding.
- R8 SHOULD — If published as a page/doc, the link opens and renders at phone width; the chat reply gives the answer + the link, not the whole document.
- R9 SHOULD — Durable findings written to shared memory with a pointer to the report.
