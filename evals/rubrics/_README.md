# Deliverable rubrics (hand-curated — do NOT let agents auto-edit these)

Used by the `review-work` skill and the `work-reviewer` agent. Each item is checkable
by EXECUTION where possible. `MUST` items block shipping when FAIL or UNVERIFIED;
`SHOULD` items become FIX entries but do not block on their own.

Edit them yourself (or approve an agent's proposed change). Research finding: curated
skills/rubrics help; self-written, unreviewed ones do not (SkillsBench, see docs/RESEARCH.md).
Best practice: when an item comes from a real incident, note the incident in a comment
so it stays grounded, and add a new item whenever the reviewer misses a real failure.

Files: app-release, customer-page, report, infra-change, data-analysis.
All of them also include the shared items in `_common.md`.
